How to Host on Vercel / GitHub Pages

1 Push Code to GitHub

Create a repository on GitHub (e.g., mockup-portal) and commit this single index.html file.

2 Deploy via Vercel (Recommended)

  1. Go to Vercel.com and sign in with GitHub.
  2. Click "Add New Project" and select your repository.
  3. Leave all build settings as default (Static HTML) and click Deploy.
  4. Your team now has a fast, live URL to view mockups anywhere!

3 How <a href="smb://..."> Links Function

Because this web app runs over HTTPS, browsers interpret smb:// links as external operating system protocol handlers. When clicked, macOS launches Finder automatically to mount/open the path.

<a href="smb://192.168.1.100/Mockups/Apparel/TShirt">Open in Finder</a>

4 Browser Recommendations

  • Safari (Mac): Opens SMB links seamlessly with 1 click.
  • Chrome / Edge: Asks for a one-time permission popup ("Allow site to open Finder?").
  • Windows Explorer: Use the "Copy Path" button for seamless pasting into Windows File Explorer address bar.
